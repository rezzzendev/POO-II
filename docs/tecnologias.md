# Tecnologias adotadas

Por decisão de Matheus: sem framework de aplicação. Java 21, HttpServer do JDK, JDBC/H2, Swing, HTML/CSS/JavaScript nativos. org.json serializa mensagens; ZXing gera/lê QR; JUnit executa testes. São bibliotecas pontuais.

Os arquivos antigos `Especificacoes` e `Tecnologias Escolhidas` registram estudos anteriores e contêm alternativas não adotadas. A configuração vigente está nos POMs e neste documento.
